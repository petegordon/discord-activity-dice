# Discord Activity Dice

A multiplayer two-dice **"7, 11, Doubles"** game with 3D dice that you shake and throw with your phone. Runs as a **Discord Activity** or standalone at **https://dice.jimandi.love**.

Built with Three.js, cannon-es, DeviceMotion, PeerJS/WebRTC, and Cloudflare Pages + Workers.
